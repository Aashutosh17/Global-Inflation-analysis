# Data

The dashboard reads `processed_inflation_data.csv`. It is generated from the
merged source dataset with `python scripts/preprocess.py`.

Source datasets:

- `world_bank_inflation_20251118.csv`
- `imf_inflation_20251118.csv`
- `merged_inflation_data_20251118.csv`

The source data was collected on 2025-11-18. Verify the applicable World Bank
and IMF terms before redistributing the files or using them commercially.
